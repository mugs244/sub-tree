# Sub-tree v2

This directory contains planning and feature specs for v2 — work that is scoped, greenlit, or proposed for the next major phase.

**v1 docs live in `docs/` (root level).** Do not add v2 content there.

## Structure

```
docs/v2/
├── README.md              ← this file
└── features/              ← one file per feature, numbered independently from v1
```

## Numbering

v2 features are numbered from **101** upward to avoid collisions with v1's 01–99 range. Reference them as `v2-101`, `v2-102`, etc.
